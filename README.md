# A Simplified 2D City Builder
A tile-based map forming the canvas upon which the city grows 
1. Basic zoning
2. Resource management, population tracking, essential utilities.
3. Simulation mechanics, such as population growth influenced by residential zones and the fulfillment of basic citizen needs.
4. Disasters

## Technology

- HTML5 
- JavaScript
- Phaser.js

## Development

### Tile-based maps
Currently 1 basic tile-map.
- A grid of small, repeating images known as tiles to construct the game environment.

### Resource management
 Tracking key metrics such as the city's population and the provision of essential services like power. 

### Zoning
 - Residential building
 - Industrial building
 - Park
 - Utility station
